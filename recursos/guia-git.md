# Guia de Commits para este repositório

## Mensagens descritivas

Bom:
- `adiciona exercícios de LEFT JOIN`
- `projeto 1: responde perguntas de receita mensal`
- `corrige consulta de top 3 por departamento`

Ruim:
- `update`
- `arquivos`
- `final final 2`

## Rotina

1. Estudou um tópico → commit nas notas
2. Resolveu exercícios → commit dos `.sql`
3. Errou e aprendeu → commit em `erros-comuns.md`
4. Concluiu uma fase → marque o checkbox no README principal e faça commit

## Comandos básicos

```bash
git add .
git commit -m "mensagem"
git push
```

## Dica

Commits pequenos e frequentes mostram constância. O gráfico de contribuições do GitHub vira prova do seu ritmo de estudo.
