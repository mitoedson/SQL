# Projeto 1: Análise de Vendas

> Substitua este título pelo do seu projeto e preencha seguindo `../README_TEMPLATE.md`.

**Objetivo:** demonstrar que você traduz perguntas de negócio em consultas SQL.

**Dataset sugerido:** Olist (e-commerce brasileiro, Kaggle), Northwind, ou outro dataset real do seu interesse.

## Checklist

- [ ] Escolhi o dataset e documentei a origem
- [ ] Importei os dados para o banco
- [ ] Documentei as tabelas e suas relações
- [ ] Escrevi de 10 a 15 perguntas de negócio
- [ ] Respondi cada pergunta com SQL
- [ ] Escrevi um insight para cada resposta
- [ ] Usei ao menos: `JOIN`, `GROUP BY`, `CASE WHEN`, CTE e uma window function
- [ ] README final preenchido

## Perguntas de partida (adapte ao dataset)

1. Qual a receita total por mês?
2. Quais categorias geram mais receita?
3. Quais são os 10 clientes que mais gastaram?
4. Qual a taxa de cancelamento de pedidos?
5. Qual o ticket médio por estado ou cidade?
6. Qual a taxa de recompra de clientes?
7. Qual o tempo médio entre o pedido e a entrega?
8. Quais produtos nunca foram vendidos?
9. Como a receita evoluiu em relação ao mês anterior?
10. Qual a participação de cada categoria na receita total?
