# Projeto 3: Projeto Final Integrado

**Objetivo:** combinar modelagem, carga de dados e análise em um projeto completo, no nível que você apresentaria em uma entrevista.

## Escopo

Modele um banco para um domínio real, popule com dados (reais ou simulados), responda perguntas de negócio e apresente conclusões.

**Domínio escolhido:**

## Checklist

- [ ] Problema de negócio bem definido
- [ ] Diagrama ER
- [ ] Schema, carga de dados e consultas em scripts separados e executáveis na ordem
- [ ] 15 ou mais consultas, com ao menos 3 usando window functions
- [ ] Pelo menos 1 análise de tendência no tempo
- [ ] Pelo menos 1 análise de segmentação (clientes, produtos ou regiões)
- [ ] Análise de desempenho: um `EXPLAIN` antes e depois de um índice
- [ ] Conclusões de negócio escritas em linguagem não técnica
- [ ] (Opcional) Dashboard no Metabase ou Power BI, com prints no README
- [ ] README completo seguindo `../README_TEMPLATE.md`

## Como destacar este projeto

- Um resumo executivo de 5 linhas no topo do README
- Prints dos resultados e do dashboard
- Seção "Decisões de modelagem" explicando por quê
- Seção "O que eu faria diferente"
